# 한국사 독립운동 정리 (시험 대비)

> 범위: 경술국치 이후 ~ 광복 전 (105인 사건 제외)
> 교과서 26~33쪽 기준 · 2026-10-10 공부 내용 정리

---

## 1. 1910년대 국내외 독립운동

### 국내
| 단체 | 특징 |
|---|---|
| **독립의군부** | 임병찬, 고종 밀지 → **복벽주의** (왕을 다시 세우자) |
| **대한광복회** | 박상진, **공화정** 목표, 군자금 모금·친일파 처단 |

### 국외
| 지역 | 단체 |
|---|---|
| **서간도** | 경학사 → 부민단 → 한족회·서로군정서 / 신흥강습소 → **신흥무관학교** (이회영·이상룡) |
| **북간도** | **간민회**(자치·교육), **중광단**(대종교 무장 → 북로군정서), **명동학교**(김약연) |
| **연해주** | 권업회 → **대한광복군 정부**(1914, 이상설·이동휘) |
| **상하이** | **동제사**(신규식) → 신한청년단(**김규식** 파리 파견) |
| **미주** | **대한인국민회**, **대조선국민군단**(박용만, 하와이) |

> ⚠️ 북간도: 간민회 = **자치 단체** / 중광단 = **무장 단체**

## 2. 3·1 운동 (1919)

- **배경**: 윌슨의 **민족자결주의**, **고종** 서거, **2·8 독립 선언**(도쿄 유학생)
- **전개**: 민족 대표 33인(**천도교·기독교·불교**) → **태화관** 선언서 낭독 / **탑골공원** 학생·시민 만세
- 농촌 확산: **장날** 이용 → 탄압 받자 **무력 저항**으로 변화 (O)
- 탄압: **제암리** 학살
- 결과: **무단 통치 → 문화 통치**, 대한민국 임시정부 수립 계기

## 3. 대한민국 임시정부

### 수립
- 1919년 3개 정부: **대한 국민 의회**(연해주) · 상하이 임시정부 · **한성 정부**(국내)
  - ⚠️ 대한광복군 정부(1914)와 헷갈리지 말 것!
- **상하이**로 결정: 서구 열강 조계 → **외교 활동에 유리**
- 한성 정부 법통 계승 → 1919년 9월 통합

### 체제
- 최초의 **민주 공화제**, **삼권 분립**
  - 입법 **임시 의정원** / 행정 **국무원** / 사법 **법원**
- 초대 대통령 **이승만**, 국무총리 **이동휘**
- "주권은 국민 전체에게 있다"

### 활동
| 분야 | 내용 |
|---|---|
| 비밀 조직 | **연통제**(국내 비밀 행정) · **교통국**(통신, 거점 = 안동 **이륭양행**) |
| 자금 | **독립 공채**, 의연금 |
| 외교 | 김규식 대표 임명, **구미 위원부**(미국, 이승만) |
| 군사 | **군무부** → 직할 부대 **육군 주만 참의부** |
| 홍보·역사 | **독립신문**, 사료 편찬소 → **『한일 관계 사료집』** |

### 위기와 개편
1. 연통제·교통국 발각, 외교 성과 부진
2. 이승만 **위임 통치 청원** → 신채호 등 비판
3. 1923 **국민대표회의**: **창조파**(새로 만들자) vs **개조파**(고쳐 쓰자) → **결렬**
4. 1925 **이승만 탄핵** → 2대 대통령 **박은식**
5. 개헌 → **국무령 중심의 집단 지도 체제** → **이동녕·김구** 중심 재정비

> 순서: 국민대표회의 결렬 → 이승만 탄핵 → 박은식 → 개헌

### 주제 탐구 인물
| 인물 | 키워드 |
|---|---|
| **조지 루이스 쇼** | 아일랜드계 영국인, 안동(단둥) **이륭양행**, 교통국 지원, 1920 체포, 1963 건국 훈장 독립장 |
| **정정화** | **임시정부의 안주인** |
| **황기환** | **외교관** (파리·영국) |

## 4. 무장 독립 전쟁

### 3막 흐름
> **이겼다** → **당했다** → **다시 뭉쳐 중국과 함께 싸웠다**

### ① 승리 (1920)
- **봉오동 전투**(6월): 대한 독립군(**홍범도**) + 국민회군(안무) + 군무 도독부(최진동)
- **훈춘 사건**: 일본이 꾸며낸 핑계 → 대규모 군대 투입
- **청산리 대첩**(10월): 북로 군정서(**김좌진**) + 대한 독립군(홍범도) 등

### ② 시련
1. **간도 참변**(1920): 일본군이 간도 한인 마을 학살 (경신참변)
2. **대한 독립 군단**(밀산) → 러시아 자유시 이동
3. **자유시 참변**(1921): 지휘권 다툼 + 러시아 적군 무장 해제 → 큰 피해 → 만주 귀환

### ③ 3부 (1920년대 중반)
| 이름 | 위치 | 특징 |
|---|---|---|
| **참의부** | 압록강 건너편 | **임시정부 직할** |
| **정의부** | 남만주 | |
| **신민부** | 북만주 | 자유시에서 돌아온 독립군 중심 |

- 민정 + **군정** 조직, **세금** 징수 → 사실상 **자치 정부**
- 외우기: **참·정·신** (참 정신!)
- 1925 **미쓰야 협정**: 만주 군벌이 독립군 체포해 넘기면 상금 → 위축

### ④ 3부 통합 → 한중 연합 작전 (1930년대 초)

```
                  1931 만주 사변 → 만주국
                │
        ┌───────┴────────┐
     남만주              북만주
   국민부              혁신 의회
   조선 혁명당          한국 독립당
   조선 혁명군          한국 독립군
   (양세봉)            (지청천)
   + 중국 의용군        + 중국 호로군
   영릉가·흥경성        쌍성보·대전자령
   양세봉 전사→약화      중국 관내 이동→한국광복군
```

- 외우기: **남조선, 북한국** / 양세봉 = ㅇ영릉가·ㅎ흥경성 / 지청천 = 대**전자**령
- ⚠️ 조선 혁명군·한국 독립군 모두 **민족주의 계열**

### ⑤ 사회주의 계열
- 중국 공산당 → 동북 인민 혁명군 → **동북 항일 연군** (한인 사회주의자 참여)
- 한인 유격대원 + 민족주의자 → **조국 광복회**

### 순서 한 줄
> 봉오동 → 청산리 → 간도 참변 → 자유시 참변 → 3부 → 미쓰야 협정 → 3부 통합 → 만주 사변 → 한중 연합

## 5. 내가 자주 틀린 것 ✍️

| 헷갈린 것 | 정답 |
|---|---|
| 북간도 대종교 무장 단체 | **중광단** |
| 상하이 신규식 단체 | **동제사** |
| 3·1 운동 후반 무력 저항? | **O** |
| 1919 연해주 임시정부 | **대한 국민 의회** (대한광복군 정부 ❌) |
| 임정 입법 기관 | **임시 의정원** |
| 군사 담당 부서 | 군무**부** (군무원 ❌) |
| 개편 체제 | **국무령 중심의** 집단 지도 체제 |
| 국민대표회의 vs 이승만 탄핵 | **회의 결렬이 먼저** |
| 남만주 / 북만주 군대 | **남 조선 혁명군 / 북 한국 독립군** |
| 한국 독립군의 이후 | **한국광복군** |
| 서울 진공 작전 vs 국내 진공 작전 | 서울 = 1908 의병 / 국내 = 1920 독립군 |
